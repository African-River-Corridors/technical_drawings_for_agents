# Golden emit fixtures

Byte-for-byte output of the packaged example generators, **run with no `EmitPolicy`
and no layer table anywhere** — i.e. the default, non-opted-in path. `test_provenance.py`'s
`test_existing_generators_produce_unchanged_bytes_when_not_opted_in` asserts
against these, and that is the whole backward-compatibility story of P3 (#55):
deterministic emit is opt-in, so nothing here may move without a policy.

**Provenance of these files.** Generated from `origin/main` at `98696d3`
(the commit P3 branched from), on the pinned toolchain — `ezdxf 1.4.4`,
`matplotlib 3.11.1`, CPython 3.14 — and verified byte-identical to the same
generators run on the P3 branch. They are the A/B evidence that P3 changed no
existing output, not a hash somebody typed in.

| File | What it is | Asserted by |
|---|---|---|
| `EXA-CIV-SEC-001.svg` | `drawings/example/simple-section` SVG, raw bytes | `test_provenance.py`, `test_layers.py` |
| `EXA-CIV-SEC-001.dxf.masked` | the same drawing's DXF, through `mask_dxf_volatiles()` | `test_provenance.py`, `test_layers.py` |
| `SYN-PSK-PID-001.svg` | `drawings/example/synthetic-pid` SVG, raw bytes | `test_provenance.py` |
| `packaged_unit_plan.svg` | `components/examples/packaged_unit.yaml` placed plan, emitted by `to_svg` with **no** `pens=` — the pre-P7 single-pen path | `test_layers.py` |
| `legacy_drawing_render_pre_p9.svg` | `Drawing(600, 400, vb, title_block=…).render()`, the legacy pixel title-block path | `test_p9_backward_compat.py` |

| `dimensions_example_pre_p11.txt` | `components/examples/site_dimensions.yaml` through `measure` → `setting_out_table` → `render_dimensions` → `check_dimensions`, as text | `test_chains.py` |

**The three P9 goldens** exist to pin the claim that P9 *adds* a third title-block
implementation and changes neither existing one (spec §4.4). They are written and
compared through `provenance.write_text_canonical` on **both** sides: byte parity
means bytes, and the trailing-newline rule is part of P3's canonical text-write
policy. Comparing a raw `render()` string against a stored file is how a sibling
implementation lost a PR to a single `\n`.

**The P11 golden** (`dimensions_example_pre_p11.txt`) exists for the same reason and was
made the same way: generated by running `test_chains.py::_example_render`'s body against
`origin/main` at `f1851dc` — pre-P11 code, reached with
`PYTHONPATH=<main-worktree>/technical_drawings_for_agents/src` — and verified byte-identical on the P11
branch. It pins spec §6's first constraint: a dimensions file with **no `chains:` block**
produces the same measurements, setting-out table, findings, annotation boxes and SVG
elements as before the chain check existed. It is a text digest rather than a rendered
sheet because those five surfaces are the whole of what P11 could have perturbed, and none
of them carries a volatile field (no timestamp, no GUID, no absolute path), so it needs no
masking.

P7 (#59) reuses this directory rather than adding a second one, and its
`test_the_example_dxf_regenerates_to_the_masked_golden` compares against
the **masked** DXF golden above for the reason recorded in issue #101: the DXF
committed under `drawings/example/simple-section/out/` predates P3, so asserting
byte-equality against *that* file is unsatisfiable by construction and cost two
sibling PRs a red build.

## Why the DXF is masked, and why these are files rather than pinned hashes

`ezdxf` re-rolls two GUIDs and rewrites `$TDCREATE` / `$TDUPDATE` and its own
marker string on every save, so an **unmasked** DXF cannot be a golden file at
all — which is exactly the defect P3 fixes. `mask_dxf_volatiles()` replaces those
six items with fixed placeholders; everything else is compared verbatim.

They are committed as **artifacts, not `sha256` vectors**, deliberately. A pinned
digest fails identically whether we regressed or whether a dependency changed
its output, so it cannot tell a reviewer which happened. A golden file fails with
a readable diff that answers the question on sight.

## When one of these legitimately changes

Do not regenerate to make a test pass. Establish which it is first:

* **a dependency bump** — the diff is confined to library-authored regions
  (`CLASSES` ordering, `$ACADVER`, a `/Producer` string). Regenerate, and say in
  the commit which version moved and why the drawing is unaffected. Note the
  committed `drawings/example/*/out/*.dxf` artifacts are *older* than these
  goldens: they were written by an earlier `ezdxf` whose `CLASSES` section
  ordered `LAYOUT` before `ACDBPLACEHOLDER`. That is pre-existing drift in
  checked-in artifacts, not a P3 regression.
* **a real emit change** — the diff touches geometry, text, or attributes.
  Regenerate only with before/after renders attached to the PR, per the
  Engineering Drawings as Code workflow. A moved coordinate is a drawing change
  and gets reviewed as one.

Regenerate with:

```bash
python - <<'PY'
import runpy, shutil, sys, tempfile
from pathlib import Path
repo = Path("technical_drawings_for_agents").resolve()
dest = repo / "tests" / "goldens"
sys.path.insert(0, str(repo / "src"))
from technical_drawings_for_agents.provenance import mask_dxf_volatiles
from technical_drawings_for_agents import pid

tmp = Path(tempfile.mkdtemp())
work = tmp / "simple-section"
shutil.copytree(repo / "drawings/example/simple-section", work)
sys.path.insert(0, str(work))
runpy.run_path(str(work / "source.py"), run_name="__main__")
shutil.copyfile(work / "out/EXA-CIV-SEC-001.svg", dest / "EXA-CIV-SEC-001.svg")
(dest / "EXA-CIV-SEC-001.dxf.masked").write_text(
    mask_dxf_volatiles((work / "out/EXA-CIV-SEC-001.dxf").read_text(errors="ignore")),
    encoding="utf-8", newline="\n")

pwork = tmp / "synthetic-pid"
shutil.copytree(repo / "drawings/example/synthetic-pid", pwork)
pid.build(pwork / "SYN-PSK-PID-001.pid.yaml", pwork / "out")
shutil.copyfile(pwork / "out/SYN-PSK-PID-001.svg", dest / "SYN-PSK-PID-001.svg")

# packaged_unit_plan.svg — the no-pens component SVG path (P7 #59). Note the
# deliberate absence of pens=: this golden exists to prove the layer table
# changed nothing for callers that did not opt in.
from technical_drawings_for_agents.components import load_component, place
from technical_drawings_for_agents.components.emit import to_svg
from technical_drawings_for_agents.svg import ViewBox
placed = place(
    load_component(repo / "src/technical_drawings_for_agents/components/examples/packaged_unit.yaml"),
    "plan", origin=(0.0, 0.0),
)
(dest / "packaged_unit_plan.svg").write_text(
    "\n".join(to_svg(placed, ViewBox(-4, 4, -3, 3, 800, 600, padding=40))) + "\n",
    encoding="utf-8", newline="\n")
PY
```

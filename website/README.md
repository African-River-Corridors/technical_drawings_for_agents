# Website

The docs page for Drawing Format Standard (DFS). Served at **https://www.africanrivercorridors.com/dfs** once it is
switched on.

## How it is served

- `.github/workflows/website.yml` checks the links on a pull request and deploys this folder to GitHub
  Pages on `main`.
- The ARC website proxies `/dfs` and `/dfs/*` to the Pages site. There is one source, this folder.
- So every local URL is an absolute `/dfs/...` path, with no trailing slash and no `.html`.
  `check_links.py` fails on anything else.
- No third-party request: the fonts are in `fonts/`.
- Claims on the page match what is released.

## What is here

| Path | What it is |
| --- | --- |
| `index.html`, `site.css` | The page. Plain HTML and CSS, no script. |
| `tokens.css`, `fonts/` | The ARC open library colours and type, and the fonts (SIL OFL 1.1, licences beside them). |
| `assets/` | The mark, lockups and favicon. Generated by the ARC open library brand pack; do not edit them here. |
| `check_links.py` | Fails on a broken or relative link. |

The look is shared by ARC's open libraries (OTD, ORD and the Drawing Format Standard). Change it in the brand
pack, then copy the page here; do not let the three pages drift apart.

## Go live

The maintainer turns on GitHub Pages for this repo (source "GitHub Actions") and adds the `/dfs` and
`/dfs/:path*` rewrites to the ARC site's `vercel.json`.

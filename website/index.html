Drawing Format Standard (DFS)

Engineering drawings as data, for AI agents. One JSON file describes a whole drawing sheet. The reference implementation checks it and gives you an SVG, a PDF and a DXF.

  • Standard: 1.2
  • Reference implementation: Python
  • Licence: Apache 2.0

What it is

  • For agents and scripts. A drawing is data. You write JSON, check it against a JSON Schema, and build it. You never write drawing code.
  • Same drawing, any implementation. Two implementations are the same when they give the same normalised content: a sorted list of entities in paper millimetres. A conformance suite holds the cases.
  • Loud failure. A value that disagrees with the drawing, a text that does not fit its cell, an undeclared layer, a window that does not fit its scale: each is an error that names the clause.

Try it

The Python package is not on PyPI yet. Install it from a checkout:

git clone https://github.com/African-River-Corridors/technical_drawings_for_agents
cd technical_drawings_for_agents
python -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/technical_drawings_for_agents build hello.drawing.json --out out/

The repository's README has hello.drawing.json and a guide to every member of a drawing document.

What it does not claim

The standard bases sheets, scales, lines, title blocks, lettering and dimensions on the ISO drawing standards. The ISO texts were not at hand when it was written, so every value taken from an ISO part is marked pending ISO check. The standard is not certified.

# Roadmap

Short and living. Each item becomes a GitHub issue labelled `roadmap`; comment there to help shape it.

- **PyPI publication** — `pip install technical_drawings_for_agents`, released from tags by trusted publishing.
- **Agent harness integration** — drive drawing builds from the agent harness, with review bundles as outputs.
- **More drawing types** — longitudinal profiles, cross-section galleries on one sheet, plan-and-profile
  sheets, and richer P&ID symbol libraries.
- **A public example on open data** — a worked river example on a downloadable open DEM.

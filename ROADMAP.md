# Roadmap

Short and living. Each item becomes a GitHub issue labelled `roadmap`; comment there to help shape it.

- **PyPI publication** ([#1](https://github.com/African-River-Corridors/technical_drawings_for_agents/issues/1)) — `pip install technical_drawings_for_agents`, released from tags by trusted publishing.
- **Agent harness integration** ([#2](https://github.com/African-River-Corridors/technical_drawings_for_agents/issues/2)) — drive drawing builds from the agent harness, with review bundles as outputs.
- **More drawing types** ([#3](https://github.com/African-River-Corridors/technical_drawings_for_agents/issues/3)) — longitudinal profiles, cross-section galleries on one sheet, plan-and-profile
  sheets, and richer P&ID symbol libraries.
- **A public example on open data** ([#4](https://github.com/African-River-Corridors/technical_drawings_for_agents/issues/4)) — a worked river example on a downloadable open DEM.
